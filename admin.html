Data and security notes

  • Local browser storage is device/browser-specific and can be cleared by the browser.
  • Shared catalog/settings require Vercel environment variables and the Supabase table documented in LIVE-BACKEND-SETUP.md.
  • Never put Stripe secret keys or Supabase service-role keys in this HTML file or any client-side JavaScript.
  • This password gate is not a replacement for server-side authentication; anyone who can inspect the HTML can see client-side logic.

Required Vercel environment variables

VariablePurpose
STRIPE_SECRET_KEYStripe server-side API secret (use test key while testing).
STRIPE_WEBHOOK_SECRETSigning secret shown for your Stripe webhook endpoint, usually starts with whsec_.
SUPABASE_URLSupabase project URL used by the server API.
SUPABASE_SERVICE_ROLE_KEYPrivate service-role key; server only, never in HTML.
ADMIN_SYNC_TOKENStrong private token used by admin-to-server sync.
In Vercel: Project → Settings → Environment Variables. Add the variables for Development/Preview/Production as appropriate, save, then redeploy. In Stripe Dashboard → Developers → Webhooks, add your deployed endpoint URL ending in /api/webhook, choose the payment events you need, and copy the endpoint signing secret into STRIPE_WEBHOOK_SECRET. Do not paste secret values into this admin page.

Current integration status: the server webhook endpoint verifies and stores Stripe webhook events when configured. A complete checkout/payment and paid-order fulfillment pipeline still needs to be wired to Stripe and the catalog.
